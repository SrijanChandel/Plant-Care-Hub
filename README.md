# PlantCare Hub — Static Demo

A responsive, single-page static demo for the PlantCare Hub SEO project.

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual design
- `script.js` — demo interactions

## Run on your Mac
1. Unzip the project folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No npm, build step, database, or API key is required.

## Demo interactions
- Plant finder changes the suggested plant based on selected answers.
- Plant problem cards show rule-based educational suggestions.
- Plant cards can be saved/unsaved in the current page session.
- Care planner checklist updates its progress and can be reset.
- Mobile navigation opens and closes.

## Notes
- This is a front-end demonstration, not a production plant diagnosis tool.
- Plant-care suggestions are general educational guidance, not a definitive diagnosis.
- Images load from Unsplash and fonts from Google Fonts, so those visual assets need an internet connection.
- Planner progress and favourites are not saved permanently.
- The current page uses anchor sections to demonstrate the proposed information architecture. The URLs in the SEO plan can later become separate pages.
